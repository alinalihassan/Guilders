The pages under [OpenAPI Reference](/api-reference) are generated from the live API schema.

On the hosted product that is [guilders.app/openapi/json](https://guilders.app/openapi/json). A Scalar explorer is also available at [guilders.app/openapi](https://guilders.app/openapi).

Use an API key from **Settings → Developer** when trying authenticated routes. For a self-hosted API, the same `/openapi` and `/openapi/json` paths exist on your origin.
